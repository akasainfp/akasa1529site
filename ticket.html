Ticket System

GitHub Pages は静的サイトなので、サイト単体では問い合わせ内容を保存できません。そこで、用途別に外部サービスへ送る方式にしています。管理しやすさと安全性のバランスが良い構成です。

Discord Ticket問い合わせ、要望、不具合報告はこのチャンネルに送ってください。 Join Discordサーバーに未参加の場合は、まずこの招待リンクから参加してください。 Channel参加済みの場合は、問い合わせチャンネルを直接開けます。

Recommended

  • 問い合わせ先: Discord の指定チャンネル
  • 未参加の場合: Discord 招待リンクから参加
  • サイト上では個人情報を送信・保存しません
